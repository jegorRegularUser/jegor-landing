## 1. Концепция и tone of voice

**Метафора.** Сайт — это комплект рабочих чертежей Егора. Контур обведён по силуэту, размеры
проставлены, штамп «УТВЕРЖДЕНО» стоит — осталось промерить курсором. Каждая секция — «лист» с рамкой
по мотивам ГОСТ 2.104, mono-шапкой «ЛИСТ NN / НАЗВАНИЕ» и миллиметровкой-подложкой. Тёмная тема —
классическая синька (прусский синий, белые линии), светлая — ватман с тушью и карандашными пометками.
Обе — строгий монохром + один сигнальный «редлайн» (оранжево-красный) + подчинённый чертёжно-голубой.

**Ин-ворлд словарь** (весь UI живёт внутри фикции чертежа):
лист, состав комплекта, экз. единств., ИЗМ. 01 (смена темы), изделие (проект), документ (сертификат),
позиция (строка спецификации), монтажная ось (таймлайн), основная надпись (штамп), масштаб 1:1,
Н.В. (настоящее время), УТВЕРЖДЕНО К СБОРКЕ.

**Tone of voice:**
- Инженерный, сухой, точный. Тексты — как надписи на чертеже: caps-mono лейблы, короткие
  номенклатуры, никаких маркетинговых восклицаний и «амбиций переосмыслить веб».
- Цифры честные: возраст «20», годы, версии стека — как в брифе, без приукрашивания.
- Человеческий слой — карандашные пометки «от руки» (2–3 на лист, лимит константой
  `MAX_PENCIL_MARKS = 3`, DEV-варн при превышении). Пометка никогда не несёт фактов, только тон.
- Юмор допустим только в форме чертёжного канцелярита («ТЕЛЕФОН — НЕ ПУБЛИКУЕТСЯ»,
  «СКРИНЫ — ПОЗЖЕ», «РУКА НА СТОЛЕ → ПИШЕТ КОД»).
- Запрещено: эмодзи, градиентные кнопки, скругления >4px, тени «material», любой цвет вне палитры §2.

**Сигнатурные моменты:**
1. **CAD-курсор** — постоянный, на всей странице: две волосяные линии 1px крестом через лист +
   mono-бейдж «X 0842 · Y 1204 · ЛИСТ 03 / ОПЫТ». Подробности §4.0.
2. **Осциллограф** — единственный shadergradient-инстанс, окно-прибор за фото-вырезкой в hero,
   фокус лерпится за CAD-курсором. §5.
3. **Штамп «ИЗМ. 01»** — смена темы шлёпает штамп. §6.
4. **Штамп «СКОПИРОВАНО»** — копирование email в §4.7.

**Стилизация по мотивам ГОСТ, не копия.** Шрифты — Oswald/IBM Plex (настоящие ISOCPEUR/GOST type A
не на Google Fonts) — осознанный компромисс, зафиксирован, споры закрыты.

### 2.3 Правила применения

- Один сигнальный цвет на экран в кадре: `--accent` используется точечно (кикер, штамп статуса,
  активный узел). `--accent2` — служебный «приборный», им много можно, ярко — нельзя.
- Все rough-обводки рисуются цветом из CSS-переменных в момент рисования (`getComputedStyle`), §6.4.
- Фотографии/скрины — «фото-вклейки»: обязательная rough-рамка + mono-подпись +
  `filter: saturate(0.85)` в обеих темах (правило для всех цветных ассетов, закреплено редизайном жюри).
- Синька — риск low-contrast blue-on-blue в деталях: при вёрстке не класть `--muted` на `--accent2`
  и не делать тонкие линии `--accent2` на `--surface` без проверки контраста (см. §10.2).

## 3. Типографика

### 3.1 Семейства и роли

| Семейство | Начертания | Роль |
|---|---|---|
| Oswald | 500, 600 | дисплей: имя, заголовки листов, названия компаний/проектов. UPPERCASE, letter-spacing 0.05–0.08em |
| IBM Plex Sans | 400, 500, 600 | тело: абзацы, описания. 16–18px, line-height 1.65 |
| IBM Plex Mono | 400, 500 | вся инженерная обвязка: даты, координаты, штампы, размерные подписи, теги стека, кикеры. 12–14px, лейблы uppercase, tracking 0.08em |
| Neucha | 400 | только карандашный слой (§4.0), 18–22px, rotate ±2°, цвет `--muted` |

Подключение: Google Fonts css2, `display=swap`, сабсеты cyrillic+latin (кириллица подтверждена —
прогон Д2). Fallback-стеки: `Oswald, "Arial Narrow", sans-serif`; `"IBM Plex Sans", system-ui, sans-serif`;
`"IBM Plex Mono", ui-monospace, monospace`; `Neucha, "Comic Sans MS", cursive`.
Вес woff2 — в бюджете §10.1. Предзагрузка: два критических woff2 (Oswald 600 latin+cyrillic,
Plex Mono 400 cyrillic) через `<link rel="preload">`; остальное — swap.

### 3.2 Размеры

- Имя в hero: `clamp(3rem, 9vw, 7.5rem)`, Oswald 600, две строки («ЕГОР» / «ДВОЙНЯКОВ»).
- Заголовок листа: `clamp(1.8rem, 4vw, 2.6rem)`, Oswald 500.
- Тело: 16px мобайл → 18px ≥768px.
- Mono-микролейблы: **≥13px** всегда (требование читаемости из refinedDirection); 12px запрещено.
- Межабзацный отступ 1em; максимальная ширина текстовой колонки 62ch.

### 3.3 Правила анимации текста

- **SplitText по словам** для заголовков листов (stagger 0.02, clip).
- **Посимвольно (chars, clip) — только имя в hero**: посимвольный клип заголовков ломает кернинг
  Oswald при letter-spacing 0.05–0.08em (решение жюри, нормативно).

### 3.4 Рукописный слой

Neucha 400 (cyrillic подтверждён прогоном Д2). Используется исключительно компонентом
`<PencilMarks>`: 2–3 пометки на лист, абсолютное позиционирование, rotate −2…+2°,
цвет `--muted`, при `prefers-reduced-motion` — просто видны. Контент пометок — ключи словаря §7.
Если при подключении у Neucha что-то изменится с кириллицей — рукописный слой заменяется на
rough-notation-пометки без нового шрифта (фолбэк, решение принимает исполнитель по факту).

## 4. Посекционная спецификация

### 4.0 Общие приёмы (нормативны для всех листов)

**Лист.** `<section class="sheet" id="sheet-0N" aria-labelledby="sheet-0N-title">`. Двойная рамка:
внешняя 1px `--hairline`, внутренняя 1.5px `--ink` с отступом 8px. Засечки-риски 10px через каждые
40px по кромкам; координатные метки «1–8» (верх) и «А–Д» (лево) mono 13px `--muted` — только ≥768px.
Hero дополнительно: утолщённая левая кромка 4px + метки A/1/2/3. **<480px:** одинарная рамка, риски
только сверху/снизу, миллиметровка выключена.

**Миллиметровка** (CSS-фон блока `.sheet__paper`, поверх `--bg`):

```css
background-image:
  linear-gradient(var(--grid-minor) 1px, transparent 1px),
  linear-gradient(90deg, var(--grid-minor) 1px, transparent 1px),
  linear-gradient(var(--grid-major) 1px, transparent 1px),
  linear-gradient(90deg, var(--grid-major) 1px, transparent 1px);
background-size: 8px 8px, 8px 8px, 40px 40px, 40px 40px;
```

**Шапка листа:** mono-кикер «ЛИСТ 03 / ОПЫТ РАБОТЫ» цветом `--accent` + тонкая линейка + Oswald-заголовок.

**Ревил листа (все листы, ScrollTrigger, once):**
`gsap.from(sheet, { y: 48, rotate: 0.4, autoAlpha: 0, duration: 0.6, ease: 'power2.out',
scrollTrigger: { trigger: sheet, start: 'top 85%', once: true } })`.
Родительские reveal-твины создаются в `useLayoutEffect` **родителя** — детские rough-инъекции
(`useLayoutEffect` детей исполняется раньше) успевают замерить layout до первого кадра твина.
reduced-motion: твин не создаётся, лист сразу в финальном состоянии.

**Карантин DrawSVG/rough:** DrawSVG — только на чистых SVG (выноски, размерные линии, линейки, ось,
прогресс). Rough-фигуры анимируются **только opacity/transform** (конфликт stroke-dasharray, ресёрч
брифа). Запрет вызовов rough внутри scroll-хендлеров — константой кода: архитектурный vitest-тест
сканирует `src/` на `registerRough|redrawAll` внутри коллбеков `onUpdate|onToggle` (regex-скан
достаточен) + пункт ревью-чеклиста.

**CAD-курсор** (`<CadCursor/>`, портал в body, `aria-hidden`, `pointer-events:none`):
- Гейт: `matchMedia('(pointer: fine)')` И ширина ≥1024px И не reduced-motion И не выключен
  пользователем (кнопка в шапке, `localStorage['jegor-cad']`, дефолт — включён).
- Две волосяные линии 1px крестом через viewport: вертикальная и горизонтальная, цвет `--accent`
  в hero (по факту активного листа = 01), иначе `--accent2`; opacity 0.4, в плотных зонах
  (сетки чипов и сертификатов — по IntersectionObserver этих секций) — 0.25.
- Бейдж у курсора: mono 13px «X 0842 · Y 1204 · ЛИСТ 03 / ОПЫТ»; координаты курсора в viewport,
  padStart(4,'0'), обновление textContent в rAF только при изменении; активный лист — из того же
  IntersectionObserver, что и подсветка «состава комплекта» в шапке.
- Стоимость: 2 div + label, rAF-цикл единый с бейджем. rough не трогает.

**Карандашные пометки** (`<PencilMarks marks={...}/>`, лимит 3): контент — §7, на каждом листе 1–3.

**Ссылки (все):** постоянное подчёркивание `text-decoration: underline 1px; text-underline-offset: 3px`
(доступность) + усиление на hover/focus-visible — «размерная линия»: inline-SVG-фон (линия со
стрелками на концах) снизу, `scaleX 0→1`, 200ms. Фокус тоже анимирует — клавиатурный паритет.

**Focus-visible:** `outline: 2px solid var(--accent2); outline-offset: 2px` — глобально, все
интерактивы (кнопки-стрелки, штампы-кнопки, тумблеры, чипы, ссылки, карточки).

### 4.1 ЛИСТ 01 — Hero («Титульный лист»)

**Layout (≥1024px):** grid 55/45, min-height 100svh. Слева: mono-кикер «ЧЕРТЁЖ № 2026-Ф1 • ЭКЗ.
ЕДИНСТВ.» (`--muted`, номер — `--accent`); `h1` имя в две строки; mono-обозначение
«FRONTEND-РАЗРАБОТЧИК • 20 ЛЕТ • НИЖНИЙ НОВГОРОД»; ряд контактов-полей: TG @panteloma /
email / github.com/jegorRegularUser (ссылки с размерным подчёркиванием). Справа: композиция фигуры.
**Мобайл:** фото НАД текстом, остаётся одна выноска, штамп переезжает под текст, min-height auto.

**Композиция справа (слои, задом наперёд):**
1. **Окно осциллографа** — прямоугольник ~440×560px, смещён за фигуру; тёмная тема: WebGL-канвас
   (§5), opacity 0.55, **без mix-blend-mode** (Safari-риск блендинга поверх WebGL снят структурно —
   решение вместо эксперимента с soft-light); рамка окна — rough seed 51. Светлая тема: вместо
   канваса — «Спецификация свечения» (§5.4), hachure-прямоугольник seed 610 + печатная легенда
   триады. Переключение тем — swap видимости слоёв, CSS-переход цветов переменных.
2. **Фото-вырезка** — `<picture>` avif→webp (кроп по пояс из RGBA 1696×2528, §8), eager,
   `fetchpriority="high"` (кандидат LCP), `width/height`, alt «Егор Двойняков за рабочим столом,
   рука на столе». Тёмная вырезка на синьке — спайк Э4(в): если сливается — подложка-тень
   `drop-shadow(0 0 24px rgba(10,30,51,0.8))`/бумажная подложка.
3. **Rough-обводка силуэта** — по готовому SVG-пути (viewBox 1000), «двойной штрих»: карандашный
   проход (roughness 2.2, strokeWidth 1.2, `--muted`) → поверх чернильный (roughness 1.4,
   strokeWidth 2.5, `--ink`), оба Drawable из **seed 42**, предрасчитаны при инициализации,
   анимация opacity/transform. **Гейт path-first (спайк Э4(а))** до вёрстки hero: наложить путь на
   реальный PNG в масштабе 100%; промах → дефолт-композиция «фото в rough-рамке (seed 51) со
   «скотчем» (CSS-полоски) и бумажной подложкой» — это полноценный план, не аварийный.
4. **Выноски** — чистые SVG (линия + стрелка + mono-текст): «г. НИЖНИЙ НОВГОРОД → 56.3°N»,

## 5. Градиент: решение архитектора и параметры

### 5.1 Решение

**Route C — raw WebGL fullscreen-quad. НЕ `@shadergradient/react`, НЕ three.js.**
Замеры архитектора (esbuild@0.28.2, `--bundle --minify --format=esm --target=es2020`, gzip):

| Маршрут | Состав | Gzip |
|---|---|---|
| A: пакет | react-dom 19.3.1 + @shadergradient/react@2.4.20 + three@0.187.0 + @react-three/fiber@9.8.2 | 352 394 B |
| B: vanilla three | three + свой модуль | 133 646 B |
| **C: raw quad** | свой модуль ~128 строк | **1 878 B** |

Аргументы: (а) 186× меньше пакета; (б) приём «u_mouse за CAD-курсором» пакетом невозможен — grep
`uMouse` по дистрибутиву пакета пуст, пропсы мышь не экспонируют; (в) у пакета нет dependencies,
three+fiber тянутся молча, декларации несовместимы с fiber v9. Артефакт: `%TEMP%/arch-scripts/
C_raw_webgl.ts` (прочитан в этой сессии) — перенести в `src/shader/quad.ts`, не переписывая логику.

### 5.2 Ядро (из артефакта, нормативно)

Вершинник — oversize-треугольник `[-1,-1, 3,-1, -1,3]`; фрагмент — Simplex-noise (Ashima, mod289/
permute/taylorInvSqrt) + `fbm` 3 октавы:

```glsl
vec2 focus = vUv + (uMouse - vUv) * 0.35;      // фокус лерпится за CAD-курсором
float n  = fbm(vec3(focus * 1.6, uTime * 0.12));
float n2 = fbm(vec3(focus * 3.2 + 7.3, uTime * 0.18));
float h  = n * uAmp + n2 * 0.35;                 // uAmp = 1.1
vec3  c  = mix(uC1, uC2, smoothstep(-0.4, 0.5, h));
c        = mix(c,  uC3, smoothstep(0.35, 0.9, h));
```

Интерфейс: `mountShaderQuad(canvas, colors): { setPaused(v), dispose() } | null` (null = no-WebGL).
Модуль сам: слушает `pointermove` (пассивно) и лерпит `mouse += (target − mouse) * 0.06` — CAD-курсор
и шейдер читают один и тот же указатель, отдельной связки не нужно; DPR cap 1.5; 30fps-кап
(`t - last < 1000/30 → skip`); resize-обработчик.

- **Dark:** канвас живёт в окне (§4.1 слой 1). Пауза: IntersectionObserver окна (порог 0) +

## 6. Механика тем

### 6.1 Pre-paint (без FOUC)

Инлайн-скрипт в `<head>` до первого пейнта (нормативный код):

```html
<script>
(function () {
  try {
    var t = localStorage.getItem('jegor-theme');
    if (!t) t = matchMedia('(prefers-color-scheme: light)').matches ? 'light' : 'dark';
    document.documentElement.dataset.theme = t;
    var l = localStorage.getItem('jegor-lang')
      || ((navigator.language || '').toLowerCase().indexOf('en') === 0 ? 'en' : 'ru');
    document.documentElement.lang = l;
  } catch (e) {
    document.documentElement.dataset.theme = 'dark';
    document.documentElement.lang = 'ru';
  }
})();
</script>
```

Тот же скрипт ставит и тему, и язык — нет расщепления гидратации (рендер клиентский).

### 6.2 CSS-переменные

`:root[data-theme='dark']` / `:root[data-theme='light']` — все токены §2. На потребителях цветов —
`transition: background-color .3s, color .3s, border-color .3s` (обычный DOM перетекает; на
reduced-motion — `transition: none`).

### 6.3 Смена темы

1. `html.dataset.theme = next; localStorage['jegor-theme'] = next;`
2. **recolor-in-place** (решение архитектора; НЕТ регенерации, НЕТ ScrollTrigger.refresh):
   по реестру оверлеев `setAttribute('stroke'/'fill', …)` из свежих `getComputedStyle
   (document.documentElement).getPropertyValue('--ink' | '--muted' | '--accent' | '--accent2')`.
   **Обязательно трогать все stroke/fill атрибуты каждого path оверлея** — цвет hachure-заливки
   rough пишет в stroke path'ов заливки, а не в fill контейнера (риск архитектора; тест — спайк
   Э4(г) на секции технологий).
3. GSAP-штамп «ИЗМ. 01» (rough-рамка seed 501): scale 1.5→1 + rotate до −8°, `back.out`, 400ms;
   гейт reduced-motion — появление без твина.
4. rough-notation: цвет `currentColor` по умолчанию (model.d.ts:21, render.js:207
   `config.color || 'currentColor'` — верифицировано архитектором) — если строка `currentColor`
   доезжает до SVG-атрибута, аннотации перекрашиваются бесплатно; если верификация покажет резолв
   цвета в момент show() — добавлять destroy+recreate аннотаций в шаг 2 (спайк Э4(д)).

Геометрическая идентичность same-seed redraw доказана (§4.9) — recolor выбран как дешёвый вариант
из двух безопасных.

### 6.4 Чтение цветов rough

rough-цвета **не хранятся в TS-палитре**: в момент рисования читаются computed-значения CSS-переменных.
Единственный источник правды, рассинхрон невозможен.

### 6.5 Жизненный цикл GSAP ↔ rough (4 хука redraw, нормативно)

1. **Маунт:** инъекции в `useLayoutEffect` секций (правило локальных координат §4.9), затем **один**
   батч-`ScrollTrigger.refresh()` (rAF после всех маунтов), не per-секция.
2. **Шрифты:** `document.fonts.ready.then(() => { redrawAll(); ScrollTrigger.refresh(); })` —
   swap шрифтов двигает текст (ресёрч брифа).
3. **Resize:** debounce 200ms → `redrawAll()` (regen с теми же seed — новые размеры, тот же
   «почерк») → `refresh()`.
4. **Морф оси:** redraw rough-узлов секции 03 в `onComplete` морфа (§4.3).

Плюс: язык — destroy+recreate rough-notation аннотаций (текст меняет метрики) + один refresh.

Метод замеров — esbuild-minified ESM (не Vite/Rollup-прод); ранжирование маршрутов надёжно,
абсолютные значения могут гулять на проценты.

после first paint), CLS ≤ 0.1 (width/height на всех картинках, swap без jump — сравнить метрики
fallback), INP ≤ 200ms (drag-слайдеры на pointer events, без heavy-работ в scroll-хендлерах).
Пагинация веса: `manualChunks` (react-vendor / gsap / rough), шейдер — динамический чанк,
`<dialog>`-PNG — по требованию.

**GitHub Pages:** кэш `max-age=600` — правки бандла видны с лагой до 10 минут; Vite-хэши имён
файлов обязательны (это кэш-бастинг), HTML — без хэша. `base: './'` в vite.config (относительные
пути работают на project-pages с любым именем репозитория); SPA-фолбэк не нужен (одностраничник,
якоря `#sheet-0N`).

### 10.2 Доступность: контраст (прогон Д1 этой сессии)

```
dark  ink/bg 13.88 | muted/bg 6.86 | accent/bg 6.48 | accent2/bg 8.68 | ink/surface 12.26 | muted/surface 6.06 | accent/surface 5.72
light ink/bg 12.74 | muted/bg 5.00 | accent/bg 4.88 | accent2/bg 4.73 | ink/surface 13.67 | muted/surface 5.37 | accent/surface 5.23
```
Все 14 пар — PASS AA для мелкого текста (≥4.5). Правило: mono-лейблы — только `--ink`/`--muted`

### 10.3 Доступность: поведение

- **reduced-motion — полный гейт (решение жюри, нормативно):** все GSAP-твины — сразу `progress(1)`
  (gsap.matchMedia); rough-notation `.show()` без draw-анимации; DrawSVG-выноски видимы сразу;
  шейдер — статичный кадр; CAD-курсор off; морф оси → кроссфейд; пульс «Н.В.» off; штампы без
  scale/rotate-твинов; CSS-transitions цветов off; `scroll-behavior: auto`.
- **Клавиатура:** skip-link → #main; таб-порядок логичен по листам; чипы — кнопки (Enter — toggle
  hachure, aria-pressed); слайдер проектов: ←/→ + кнопки-стрелки, счётчик в aria-live; лайтбокс —
  нативный `<dialog>` (Esc, фокус-ловушка, возврат фокуса); тумблеры шапки — обычные кнопки;
  focus-visible 2px `--accent2` offset 2px на всём интерактивном.
- **Семантика:** h1 (имя) → h2 (заголовки листов) → h3 (карточки); `lang` меняется со словарём;
  CAD-курсор и выноски — `aria-hidden`/декоративные; alt-тексты из словаря; контрастные пары §10.2;
  ссылки — постоянное подчёркивание (§4.0).
- **Прогон EN/360px:** вёрстка штампов и mono-лейблов на 360px в обеих локалях без переполнения —
  чеклист Э9 (глоссарий §7.2).

### 10.4 no-WebGL fallback

`mountShaderQuad → null` ⇒ `.shader-fallback` на контейнере окна: CSS-градиент из переменных темы
(§5.4), дрейф keyframes (off reduced-motion), transition переменных при смене темы. Автотест:
Playwright-спека с флагами `--disable-webgl --disable-webgl2` — ассерт «.shader-fallback видим,
канвас отсутствует»; базовая спека — ассерт канваса и одного кадра. (Playwright — devDependency;
если в окружении исполнителя браузеров нет — тест помечается `test.skip` локально и выполняется
в CI/на машине с браузером; спека теста обязательна.)

### 10.5 Совместимость

Вечнозелёные браузеры + Safari ≥15.4 (нативный `<dialog>`). Никакого mix-blend-mode поверх
WebGL-канваса (снято структурно — §4.1). WebGL-фолбэк §10.4 покрывает отсутствие WebGL.
